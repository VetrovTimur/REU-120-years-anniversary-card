# Юбилейная карта РЭУ — 120 лет

Лендинг для оформления лимитированной банковской карты к 120-летию РЭУ им. Г. В. Плеханова с **мгновенной валидацией** и **автоматической выгрузкой в Excel**.

---

## 📋 Описание

Проект представляет собой адаптивную одностраничную форму заявки на получение юбилейной карты. Состоит из четырёх шагов, содержит выбор дизайна карты, ввод персональных данных, адреса и согласий.

**Ключевые особенности:**
- 🟢 **Мгновенная валидация** — поля проверяются в реальном времени при вводе
- 📊 **Автоматическая выгрузка Excel** — после отправки заявки файл скачивается автоматически
- 💾 **Локальное хранение** — все данные сохраняются в `localStorage`
- 📱 **Полная адаптивность** — корректно отображается на всех устройствах

---

## 🛠️ Технологии

- **HTML5** — семантическая разметка
- **CSS3** — кастомные стили, Flexbox, медиазапросы
- **JavaScript (vanilla)** — управление шагами, валидация, Excel
- **SheetJS (XLSX)** — библиотека для работы с Excel-файлами
- **Google Fonts** — шрифт Inter
- **SVG** — векторные иконки
